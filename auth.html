One-time setup

Step 1 — Enter your Spotify Client ID

You only need to do this once. After this, visitors to your site will never see this page.

Make sure https://www.medisession.co.ke/auth.html is added as a Redirect URI in your Spotify app settings.

Step 2 — Copy your Refresh Token

Copy the token below. You will paste it into Vercel as an environment variable in the next step.

Copied!
Step 3 — Add to Vercel environment variables

Go to your Vercel project → Settings → Environment Variables and add these two variables:

Name: SPOTIFY_CLIENT_ID
Value: your Client ID

Name: SPOTIFY_REFRESH_TOKEN
Value: the token you just copied

After saving, go to Deployments and click Redeploy on the latest deployment. You are done — you can delete auth.html from GitHub now.
