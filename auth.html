Step 3 — Add environment variables to Vercel

Go to your Vercel project → Settings → Environment Variables and add all three:

SPOTIFY_CLIENT_ID → your Client ID

SPOTIFY_CLIENT_SECRET → your Client Secret

SPOTIFY_REFRESH_TOKEN → the token you just copied

After saving all three, go to Deployments → click the three dots on the latest → Redeploy. Done! You can now delete auth.html from GitHub.
